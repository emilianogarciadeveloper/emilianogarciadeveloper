I treat every website like a production system: it has to load fast, stay up when traffic and pressure hit, work for every user regardless of ability, and be easy for your team to maintain long after I hand it off. ## Accessibility — WCAG 2.1 AA

This is the part most developers skip and most agencies get sued over.

**500+ sites audited and remediated to Level AA since 2021.** Contrast ratios, keyboard navigation, focus management, semantic landmarks, ARIA where it belongs (and removed where it doesn't), screen-reader flows, accessible forms and error handling.

If you're an agency carrying ADA exposure on client sites — or you've received a demand letter — that's a problem I've solved a few hundred times. I work from real audits against live code, not overlay widgets. Overlays don't fix the underlying markup and don't hold up.

> **Free proof first:** send me a URL and I'll return a short audit of the actual failures — specific elements, specific criteria, specific fixes. No pitch attached.
